1. Supabase 연결 정보

3초마다 서버와 기록을 맞춰요. 인터넷이 끊겨도 이 기기 기록은 그대로 남고, 다시 연결되면 이어서 맞춰요.

2. Supabase SQL (한 번만 붙여 넣으면 끝)

supabase.com → 새 프로젝트 → SQL Editor에 아래 코드를 붙여 넣고 Run을 눌러 주세요. 표 하나만 만들면 돼요.

create table if not exists family_state (
  room_id text primary key,
  state jsonb not null,
  updated_at timestamptz not null default now()
);

alter table family_state enable row level security;

create policy "family_state_all" on family_state
  for all using (true) with check (true);
① supabase.com에서 무료 프로젝트를 만들어요.
② 왼쪽 SQL Editor에서 위 코드를 실행해요.
③ Project Settings → API에서 Project URL과 anon public key를 복사해요.
④ 위 칸에 넣고 저장하고 연결을 누르면 끝!
⑤ 가족 기기에서도 같은 방 ID로 연결하면 같은 기록을 봐요.

3. 백업 · 복원
